# Taxonomía Editorial

## Categorías Principales (Silos)
Solo un post debe pertenecer a una categoría principal para preservar el silo semántico.
- **Estrategia y Crecimiento:** Para temas de escalar negocios y toma de decisiones.
- **Arquitectura Operativa:** Para procesos, delegación e infraestructura interna.
- **Sistemas Comerciales:** Para ventas B2B, CRMs, flujos de prospectos.
- **Tecnología y Automatización:** Para adopción digital.

## Etiquetas Controladas (Contexto transversal)
- `CRM`, `Dependencia del Fundador`, `AETHRYON`, `Conversión`, `Estructura`, `Datos`.

*Nota:* No crear etiquetas ad-hoc para un solo post. Si una etiqueta no agrupa al menos 3 piezas de contenido, no debe crearse.
