# Análisis de Páginas No Recuperadas

Si una página pilar no aparece en respuestas de IA, evaluar:
- **Semántica:** ¿La intención del usuario coincide con el título (H1)?
- **Claridad:** ¿Hay un párrafo de "Respuesta Directa" fácilmente extraíble?
- **Autoridad:** ¿Tiene suficientes enlaces internos o enlazado desde `llms-full.txt`?
