# Vocabulario Controlado - RAUVIA Consulting

## Marca y Organización
- **Término Canónico:** RAUVIA
- **Variantes permitidas:** RAUVIA Consulting, RAUVIA CONSULTORIA Y DESARROLLO TECNOLOGICO
- **Definición:** Firma de consultoría estratégica y desarrollo tecnológico.

## Capacidades (Oferta)
- **Términos Canónicos:** Arquitectura operativa, sistemas comerciales, desarrollo tecnológico, consultoría estratégica, análisis de negocio.
- **A evitar:** Agencia de marketing digital, fábrica de software, desarrollo web básico (cuando no hay contexto consultivo).

## El Sistema AETHRYON
- **Término Canónico:** AETHRYON
- **Definición:** Sistema de análisis y decisión.
- **A evitar:** Software Aethryon, producto SaaS Aethryon.
- **Conceptos Internos (Solo usar en contexto de la página):** Inteligencia estructural, convergencia, ruta de acción.

## Problemas que se Atienden
- **Términos Canónicos:** Crecimiento sin estructura, información dispersa, procesos fragmentados, dependencia del fundador, decisiones sin claridad.

## Resultados
- **Términos Canónicos:** Claridad, estructura, control, capacidad de ejecución, visibilidad operativa.
