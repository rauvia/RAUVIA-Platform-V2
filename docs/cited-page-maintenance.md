# Mantenimiento de Páginas Citadas

Cuando una página (ej. `/soluciones`) es frecuentemente citada por LLMs:
- **Prioridad:** Estabilidad. No cambiar la URL (si es inevitable, usar 301 estricto).
- **Actualización:** Mantener la evidencia, actualizar el `dateModified` solo si hay cambios sustanciales, y verificar que los CTA comerciales sean claros.
