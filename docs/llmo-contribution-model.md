# Modelo de Contribución LLMO

- **Descubrimiento (Top Funnel):** El usuario pregunta a ChatGPT por "arquitectura operativa", lee sobre RAUVIA y hace clic.
- **Validación (Mid Funnel):** El usuario ya conoce RAUVIA, pero le pide a Perplexity que resuma sus servicios antes de agendar una llamada.
- *Regla:* No atribuir el 100% de la venta a la IA; la IA asiste la conversión B2B, no la cierra sola.
