# Protocolo de Corrección Externa

Si un LLM o directorio alucina (ej. dice que RAUVIA es una "Agencia de Marketing Digital"):
1. Identificar de dónde extrae el LLM la información (fuente citada).
2. Contactar al directorio/fuente para corrección.
3. Reforzar el `llms-full.txt` y JSON-LD de la web para inyectar la señal correcta.
