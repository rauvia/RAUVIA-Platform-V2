# Rúbrica de Evaluación de Respuestas LLM

Al ejecutar el Método de Consultas de Observación, clasificar la respuesta en las siguientes dimensiones usando la escala: **Correcto, Parcialmente Correcto, Incorrecto, Ausente, No Evaluable**.

1. **Presencia:** ¿Aparece RAUVIA?
2. **Precisión:** ¿La descripción de los servicios es correcta?
3. **Atribución:** ¿Se cita una URL válida del dominio `rauvia.com.mx`?
4. **Identidad:** ¿Se confunde con una agencia de marketing o software house?
5. **Relación:** ¿AETHRYON se asocia como metodología/sistema y no como un SaaS independiente?
