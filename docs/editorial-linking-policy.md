# Política de Enlazado Interno Editorial

1. **Arriba y Abajo:** Todo artículo satélite debe enlazar con ancla exacta o semántica a su "Página Pilar". La "Página Pilar" enlaza de vuelta al artículo.
2. **Contexto de Producto:** Cuando se hable de problemas comerciales, debe existir un enlace hacia `/soluciones` o al bloque del *Frente Comercial Esencial*.
3. **Anclas Naturales:** Se prohíbe el uso de "haz clic aquí". Ej. correcto: "...lo que requiere una evaluación mediante nuestro **sistema de análisis AETHRYON**."
4. **Densidad:** Máximo 3 enlaces internos profundos por cada 1,000 palabras para no diluir el PageRank.
