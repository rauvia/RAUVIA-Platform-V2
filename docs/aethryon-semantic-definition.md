# Definición Semántica de AETHRYON

## Categorización
- **Categoría Recomendada:** Sistema de Análisis y Decisión / Framework / Metodología (JSON-LD: `Thing`)
- **Lo que NO es:** No es un software comercializable independiente (SaaS), no es un producto físico, no es una empresa separada.

## Definiciones
- **Definición Canónica:** AETHRYON es el sistema de análisis y convergencia desarrollado por RAUVIA para interpretar señales, identificar fricción, evaluar oportunidades y estructurar decisiones ejecutables.
- **Descripción Corta:** Sistema de análisis de RAUVIA para identificar frenos al crecimiento y crear una ruta de acción.
- **Descripción Extendida:** AETHRYON es el marco metodológico y sistema de análisis propietario de RAUVIA. Permite a las empresas pasar de una situación de ambigüedad operativa a sistemas ejecutables, organizando el diagnóstico en fases claras: Comprender, Delimitar, Diseñar, Construir, Implementar y Medir. Ayuda a responder dónde invertir y qué iniciativa genera mayor avance.

## Relación con RAUVIA
- RAUVIA es la firma consultora (Organization).
- AETHRYON es el sistema (System/Methodology) utilizado internamente por RAUVIA para proveer sus servicios a los clientes.

## Vocabulario
- **Términos Permitidos:** Sistema de análisis, metodología, sistema propietario, framework, diagnóstico estructural, ruta de acción.
- **Términos a Evitar:** Software Aethryon, Agencia Aethryon, producto SaaS, inteligencia artificial predictiva (si no está verificado).
