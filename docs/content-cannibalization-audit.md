# Auditoría de Canibalización

- **Riesgo:** Si `/aethryon` y un post de blog llamado "Qué es Aethryon" compiten por la misma consulta, los LLMs pueden confundirse o citar la página menos relevante para conversión.
- **Acción:** Consolidar intenciones. La página de servicio es para conversión, el post es para contexto o casos de uso. Usar enlazado cruzado claro.
