# Sistema de Priorización Editorial

Para decidir qué escribir, se utilizará una matriz sencilla:

| Variable | Puntuación | Descripción |
| --- | --- | --- |
| Proximidad Comercial | 1-3 | 3 = Directamente ligado a una solución actual de RAUVIA. |
| Riesgo de Alucinación LLM | 1-3 | 3 = Alta probabilidad de que ChatGPT invente la respuesta sobre RAUVIA. |
| Evidencia Disponible | 1-3 | 3 = Tenemos casos documentados internos para sustentar el artículo. |

- **Prioridad P1 (Publicar Primero):** Score 7-9. (Ej. Qué es AETHRYON, Problemas de CRMs sin proceso).
- **Prioridad P2 (Mediano Plazo):** Score 4-6. (Ej. Crecimiento vs Estructura).
- **Prioridad P3 (Backlog):** Score 1-3. (Ej. Tendencias de IA en el futuro lejano).
