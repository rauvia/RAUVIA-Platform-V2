# Glosario Estructurado Piloto

## Términos Aprobados para `llms-full.txt` e Inyección de Contexto
1. **Arquitectura Operativa:** El diseño estructurado de procesos, flujos de información y roles de una organización para funcionar de manera predecible y escalable.
2. **Sistema Comercial (Frente Comercial Esencial):** La infraestructura mínima viable que requiere una empresa para comunicar su oferta, capturar prospectos de manera predecible y gestionarlos hasta el cierre.
3. **Crecimiento sin Estructura:** Fase empresarial donde las ventas aumentan pero la capacidad operativa colapsa, resultando en pérdida de rentabilidad y dependencia extrema del fundador.
4. **Inteligencia Estructural:** La capacidad de una organización para evaluar sus propios procesos, identificar fricciones operativas y diseñar soluciones basadas en evidencia, objetivo central del sistema AETHRYON.
5. **Convergencia Empresarial:** El proceso de alinear estrategia direccional, procesos operativos y herramientas tecnológicas hacia un único objetivo de ejecución.
